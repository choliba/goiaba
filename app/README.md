# app

Projeto básico em TypeScript com Bun.

Instale as dependências:

```bash
bun install
```

Execute o projeto:

```bash
bun run start
```

Reinicie automaticamente ao alterar os arquivos:

```bash
bun run dev
```

Verifique os tipos:

```bash
bun run typecheck
```

O ponto de entrada é `index.ts`.
